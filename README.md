# s04.github.io

Documentation sites, published with GitHub Pages at <https://s04.github.io/>.

- `index.html` — the landing page listing every project. Add a new entry here when a project's docs are added.
- `synthesis/` — built from the synthesis docs (Astro + Starlight) and deployed by that project's docs workflow through a deploy key. Do not edit by hand.

Each project lives in its own top-level folder and is served at `https://s04.github.io/<project>/`.
