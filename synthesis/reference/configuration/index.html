Configuration

This page lists every field synthesis.yaml accepts, with its type and default. For a guided explanation and advice on choosing values, see Configuration in Setup.

Durations are Go duration strings (90s, 5m, 1m30s). Relative paths are resolved against the directory that holds the config file. Unknown fields are ignored. A field left out, or set to its zero value (0, "", 0s), takes the default; the exceptions are voidstar, faults.workloadRequests and faults.intensity, where an explicit false or 0 is respected.

Top level

Section titled “Top level”
Field Type Default Description
name string synthesis Name of the system; shown in the report.
namespace string default Reserved; currently unused. synth derives namespaces from the manifests.
manifests list of paths required Files or directories of raw Kubernetes YAML/JSON to deploy each timeline.
images list of strings [] Local images imported into every node by up and build, and re-imported before each timeline when a node lost them.
build list of build [] Docker builds run by up and build before importing.
catalog list of paths [] Source trees scanned for SDK assertion call sites, so unreached assertions are reported.
voidstar bool true Mount synthesis’ libvoidstar.so and a per-timeline seed file into every pod.
cluster cluster The k3d cluster.
setup setup How readiness is decided.
composer composer Test-template scheduling.
faults faults The nemesis.
duration duration 90s Driver phase per timeline. Overridden by --duration.
quiescence duration 15s Settle time after faults are healed, before eventually_/finally_.

build

Section titled “build”

Each entry of build:.

Field Type Default Description
image string Tag to build. List it under images too, or it is not imported.
context path Docker build context, relative to the config file.
dockerfile path <context>/Dockerfile Dockerfile, relative to the config file (not to the context).

cluster

Section titled “cluster”
Field Type Default Description
cluster.name string synthesis k3d cluster name: 1–32 lowercase letters, digits and -. Node containers are k3d-<name>-server-0, k3d-<name>-agent-0, … Overridden by SYNTH_CLUSTER.
cluster.image string rancher/k3s:v1.35.5-k3s1 k3s node image.
cluster.servers int 1 Server (control-plane) nodes. server-0 is never faulted.
cluster.agents int 3 Agent nodes.
cluster.subnet CIDR 172.28.0.0/16 Node network. Static node IPs, so restarted nodes keep their address. If taken, up picks a free /16 in 172.16–31, then 10.64–127. Overridden by SYNTH_SUBNET.
cluster.args list of strings [] Extra arguments appended to k3d cluster create.
cluster.mount path .synthesis/mnt next to the config Host directory mounted at /synthesis in every node; holds pod output and helpers. Fixed at cluster creation. Overridden by SYNTH_MOUNT.

setup

Section titled “setup”
Field Type Default Description
setup.timeout duration 5m Deadline for every Deployment, StatefulSet and DaemonSet to roll out.
setup.signalGrace duration 60s How long to wait for an antithesis_setup line after rollout.
setup.requireSignal bool false When true, no signal within the grace period fails “Setup completed”. When false, a completed rollout is enough.

composer

Section titled “composer”
Field Type Default Description
composer.workloadSelector label selector synthesis.dev/role=workload Pods searched for /opt/antithesis/test/v1/ and used to run commands.
composer.template string "" (seeded choice) Force one test template by name.
composer.maxParallel int 3 Upper bound of driver parallelism; each timeline draws 1…maxParallel.
composer.commandTimeout duration 5m Per-command timeout; also how long a finally_ ending waits for running drivers.

faults

Section titled “faults”
Field Type Default Description
faults.enabled list of strings [all] Fault kinds or wildcards (all, node.*, pod.*). Wildcards never include the opt-in clock kinds. See Fault kinds.
faults.nodes agents | all agents Nodes eligible for node faults. all adds servers other than server-0.
faults.podSelector label selector synthesis.dev/fault-target=true Pods eligible for pod faults (only in the manifests’ namespaces).
faults.intensity float 0.15 Mean planned fault arrivals per second. An explicit 0 disables planned faults; workload requests still work.
faults.minDuration duration 2s Shortest planned fault.
faults.maxDuration duration 15s Longest planned fault.
faults.maxNodeFaults int 1 Nodes or pods disrupted (paused, killed, stopped) at the same time.
faults.swarm bool false Draw a random subset of the enabled kinds, a parallelism and an intensity multiplier per timeline.
faults.workloadRequests bool true Serve requests from the in-pod synthesis-fault helper. Left out means true; an explicit false is respected, and requests are then answered invalid.
faults.clock bool false Install Chaos Mesh during up even if no clock kind is enabled yet. Enabling pod.clock or pod.clock_all implies it.

Validation

Section titled “Validation”

synth refuses to start, with exit code 2, when:

  • manifests is empty;
  • faults.nodes is neither agents nor all;
  • a name in faults.enabled is not a known kind or wildcard (node.*, pod.*, all). Only the commands that plan or run timelines check this (run, explore, plan, replay, shrink, causality and validate); heal, down and clean do not, so a typo cannot keep you from cleaning up;
  • the cluster name (after SYNTH_CLUSTER) is not a valid name;
  • SYNTH_SUBNET is not a CIDR, or SYNTH_MOUNT is not an absolute path.
